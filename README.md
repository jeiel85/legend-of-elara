# 엘라라의 전설 (The Legend of Elara)

순수 정적 파일로 동작하는 젤다1 스타일 탑다운 액션 어드벤처 게임입니다.
빌드 단계 없음 · 외부 에셋 없음 (스프라이트는 canvas 절차 생성, 사운드는 WebAudio 신스).

## 실행 방법

정적 서버로 `index.html`을 서빙하세요:

```bash
npx serve .
# 또는
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/index.html` 접속.

## 조작법

- 이동: 방향키 / WASD
- 검 공격: Z / J / Space
- 아이템 사용: X / K
- 아이템 전환: C / L
- 대화/확인: E / Enter
- 인벤토리: I / Tab
- 목표 표시 토글: Q
- 음소거: M
- 모바일: 화면 터치 패드 + 검/템/E/가방 버튼

## 공략 (퀘스트 흐름)

1. 마을 촌장과 대화 → `숲의 작은 동굴에서 나무검 찾기` (마을 북쪽 숲 계단)
2. 나무검 상자 획득 → 촌장에게 복귀 → 3개 문장 조각 퀘스트 시작
3. D1 숲의 동굴(마을 북쪽): 열쇠→잠긴 문, 폭탄 균열, 보스 거대 슬라임 → 강철검 + 조각
4. D2 호수의 동굴(동쪽 섬): 보스 열쇠→보스 문, 랜턴 획득, 보스 문어왕 → 조각
5. D3 설산의 동굴(북동): 어둠 지역(랜턴 필요), 부메랑 획득, 보스 기사 대장 → 조각
6. 촌장에게 복귀 → 봉인된 문 개방 컷신 → 북쪽 성역(final)
7. 빛나는 검 획득 → 마왕 엘고르 3페이즈 → 엔딩 (플레이 시간/처치/사망/젬 통계)

## 시스템

- 저장: 석상(O) 앞에서 E + 보스/조각 자동저장, localStorage `elara.*`
- 상점: 인벤토리 상점 탭에서 구매 (포션/방패/화살/폭탄)
- 하트 조각 4개 → 최대 HP +1
- 갑옷기사: 정면 면역, 뒤잡기/폭탄 필요
- 균열(C): 폭탄, 덩굴(V): 랜턴, 밀기 블록(K), 잠긴 문(d)/보스 문(L)
- 사망: 게임오버 → 마지막 저장에서 부활, 젬 절반 소실

## 개발 노트

- 논리 해상도 480x320 (16px 타일, 30x20 뷰), 고정 timestep 60fps
- ES 모듈 상대경로만 사용 (서브패스 배포 대응)
- 타일 스프라이트 사전 렌더링 (매 프레임 생성 없음)
- 음악: square/triangle 오버월드·던전·보스 변주 시퀀서
